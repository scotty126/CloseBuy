# OmniDash

A B2C multi-vendor e-commerce marketplace with integrated delivery logistics.

## Surfaces

| Surface | Audience | Purpose |
|---|---|---|
| Customer app | Shoppers | Browse, order, pay, track delivery |
| Vendor dashboard | Sellers | Catalogue, inventory, order fulfilment, payouts |
| Rider app | Delivery riders | Job offers, pickup/dropoff, proof of delivery |
| Superadmin dashboard | Platform operators | Onboarding, moderation, disputes, finance, config |

All four are clients of one shared backend.
